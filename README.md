# 📖 Dictionary App

A modern Dictionary Application built using HTML, CSS, and JavaScript that allows users to search for word meanings, pronunciations, definitions, and examples in real time using a Dictionary API.

## 🚀 Features

- Search any English word instantly
- View definitions and meanings
- Listen to pronunciation audio
- See parts of speech
- Example sentences
- Responsive user interface
- Real-time API integration

## 🛠️ Tech Stack

- HTML5
- CSS3
- JavaScript (ES6)
- Dictionary API

## 🌐 API Used

Free Dictionary API

https://dictionaryapi.dev/

## ⚙️ Installation

1. Clone the repository

```bash
git clone https://github.com/your-username/dictionary-app.git
```

2. Navigate to the project folder

```bash
cd dictionary-app
```

3. Open `index.html` in your browser.
